# Mobility-Inspecter_Engine

**엔진룸 사진의 부품 박스를 선택하면 관련 어셈블리·부속품의 품번과 카탈로그 원문을 찾는 Android 태블릿 앱입니다.**

2023년형 일반 렉스턴 스포츠를 대상으로 합니다. 기존 오프라인 CameraX + YOLO/ONNX 탐지 흐름에 **검수 데이터셋 사진 모드와 부품 카탈로그 검색**을 추가했습니다.

## 지금 사용할 수 있는 기능

1. 검수 팩 ZIP 가져오기 → 데이터셋 원본 사진과 검수된 바운딩 박스 표시.
2. 박스 터치 또는 화면 부품 목록 선택 → 해당 부품의 본체/주요 구성과 같은 도면의 관련 부속 검색.
3. 품번·한글/영문 부품명·옵션 검색, 품번 복사.
4. 선택한 품번의 옵션·적용 시작/종료·변속기·비고·PDF 페이지 확인.
5. **품번표 원문**에서 해당 행을 빨간 테두리로 표시하거나 **분해도 보기**로 이동. 확대/축소와 앞뒤 페이지 이동 지원.
6. 학습된 YOLO 모델을 가져온 경우, 실시간 탐지 박스에서도 같은 카탈로그 검색 사용.

카메라 권한은 실시간 모드에 진입할 때만 필요합니다. 사진·모델·카탈로그는 기기 내부에서 처리하며 인터넷 권한을 요청하지 않습니다.

## 사용한 데이터

2026-10-29에 확인한 `engine_room_seed_dataset.zip` 최신본은 **사진 6장, 박스 30개**입니다.

| 실제 라벨이 있는 부품 | 박스 |
|---|---:|
| 배터리 | 6 |
| 퓨즈 박스 | 6 |
| 에어클리너 | 6 |
| 냉각수 보조탱크 | 6 |
| 엔진오일 레벨 게이지 | 6 |

데이터셋의 12개 클래스 순서를 그대로 사용하며, 나머지 7종은 라벨 0개입니다. 없는 박스를 추가하거나, 검수 박스를 AI가 예측한 것처럼 표시하지 않습니다. **검수 사진 화면은 학습 모델 없이 동작하며, 실시간 AI 탐지에는 별도로 학습된 모델이 필요합니다.** 이 변경에서 엔진룸 학습 가중치나 정확도 수치를 만들지 않았습니다.

사용자 제공 `8. 2023 렉스턴스포츠-부품카다로그.pdf` 786쪽에서 엔진룸 관련 12종의 **235개 원문 행**을 추출했습니다. 같은 품번이라도 원문에 다른 옵션/행이 있으면 보존합니다. 전체 카탈로그의 모든 부품을 색인한 것은 아닙니다.

품번은 **후보**입니다. 생산일·엔진·ISG·변속기 등 적용 조건이 다르므로 사진만으로 확정하지 않습니다. 관련 목록은 같은 도면에 있는 부속 관계이며, 모든 항목이 해당 차량에 동시에 장착된다는 뜻은 아닙니다.

## 태블릿에서 사용

- [GitHub Actions](https://github.com/Origin1332/Mobility-Inspecter_Engine/actions)의 성공한 실행에서 `mobility-inspecter-engine-debug` APK 아티팩트를 설치합니다.
- 앱의 **검수 팩 ZIP**에서 생성한 `engine_inspection_catalog_v2.zip`을 선택합니다.
- **검수 사진**에서 이전/다음 사진을 선택하고 박스를 누릅니다. 작은 박스는 **화면 부품 목록**으로도 선택할 수 있습니다.
- **카탈로그 검색**은 엔진룸 관련 색인 전체를 검색합니다. 박스에서 열면 해당 부품에 연결된 항목으로 범위를 제한합니다.
- 기존 앱과 별도로 설치되는 `com.mobility.engine` / 버전 0.2.0입니다.

원본 seed ZIP은 카탈로그가 없으므로 앱에 직접 가져오지 않습니다. 아래 도구로 검수 팩을 만들거나 제공된 검수 팩을 사용하세요.

## 검수 팩 생성

Python 3.11/3.12, 저장소 루트 기준:

```powershell
python -m pip install -r tools/requirements-catalog.txt
python tools/build_inspection_bundle.py --dataset C:/datasets/engine_room_seed_dataset.zip --catalog C:/datasets/rexton_2023_parts_catalog.pdf --output C:/datasets/engine_inspection_catalog_v2.zip
```

출력 ZIP에는 inspection.json, catalog.json, catalog.pdf와 원본 규격화 이미지가 들어 있습니다. 기존 출력 파일은 덮어쓰지 않습니다. 카탈로그 추출기는 제공된 2023년 PDF의 표 레이아웃용이며, 다른 문서의 배치가 다르면 추출 결과 검수가 필요합니다.

자료 및 이미지의 원문·사용 조건은 원본에 따릅니다. 원본 사진과 PDF, 검수 팩, 모델 가중치는 공개 Git 저장소에 넣지 않습니다.

## 학습 기능

`tools/prepare_dataset.py`, `train_export.py`, `benchmark.py`는 별도로 유지합니다. 현재 6장 seed에는 차량별 train/val/test 분할과 12종 전체의 충분한 라벨이 없으므로 **현재 seed로 이 학습 명령을 바로 실행하지 않습니다.** 검수 팩 생성은 학습 가능 판정을 의미하지 않습니다.

학습용 데이터의 클래스 순서는 `tools/contract.py`와 일치해야 합니다. 모델 출력은 클래스 이름으로 앱 ID에 매핑하므로, 추후 별도로 검증된 부분 클래스 모델도 읽을 수 있습니다. 이전 10종 초안의 모델은 알 수 없는 클래스가 있어 거부됩니다. 의미가 다른 클래스를 임의로 같은 부품에 매핑하지 않습니다.

## 검증

```powershell
python -m unittest discover -s tests -v
gradle -p android testDebugUnitTest lintDebug assembleDebug --no-daemon
```

Python: seed 좌표/규격/클래스 검사, 누수·중복 방지, 카탈로그 표의 품번·옵션·기간 분리, 관련 부속 매핑 및 검색.
Android: 좌표 복원/NMS, 클래스 이름 매핑, 카탈로그 검색과 범위 제한.
실제 태블릿에서의 카메라·터치·성능 검증은 별도입니다.
