# 구현 및 검증 상태

2026-10-28 기준.

## 기존 작업에서 확인한 내용
- 원본 저장소 main에는 계획서가 있고 앱 개발은 PR #1의 feat/android-front-inspection 브랜치에서 진행 중입니다.
- 원본 PR head: c489ce07b70ec8129c781c4ae98a88966bfb9935.
- 기존 학습 기본값은 YOLOv8n / 640 / 100 epochs. 전면 데이터는 10장·61박스이며 일부 클래스 예시가 없습니다. 학습 가중치와 실차 측정 결과는 없습니다.
- 이전 YOLO 대화의 JPG/RGB·최대 1280px·불확실 박스 제외 방침을 계승했습니다.
- 이전 엔진룸 작업은 엔진 커버·배터리·냉각수 보조탱크·흡기 호스·퓨즈 박스를 언급했으나 칸 여부 검토가 필요한 자료가 포함됩니다. 해당 자료를 검증된 일반형 학습 데이터라고 간주하지 않았습니다.

## 이번 구현
- 기존 Android 카메라/박스/한글명/신뢰도/점검 참고 UI를 엔진룸에 맞춤.
- 별도 앱 ID, 엔진룸 task 검증, YOLOv8/YOLO11 공통 raw detection ONNX 계약.
- 640/960/1280 입력과 후보 수 8400/18900/33600 지원.
- 차량 그룹 분할, 검수/차종 조건, RGB/해상도, 중복 픽셀, 클래스별 분할 예시, bbox 검증.
- 동일 엔진룸 데이터에서 기준 모델과 후보를 비교하는 학습/평가 명령.
- 체크포인트와 실제 test 이미지/라벨 해시, mAP 및 클래스별 recall, 측정 PC의 추론 속도 기록.
- 정확도 gate와 실제 배포 가능 상태를 분리. 성능 개선 목표를 실측 결과처럼 표시하지 않음.

## 검증
- 로컬 Python 테스트 12개 통과: 좌표 변환, 분할 누수, 차종, 미검수, 중복, 잘못된/NaN 박스, 누락 클래스, 경로, 텐서 후보 수, 성능 gate, Python/Android 클래스 일치.
- 로컬 환경에는 JDK/Gradle이 없어 Android 빌드는 GitHub Actions에서 수행하도록 구성.
- 학습/ONNX 실모델 내보내기, 엔진룸 정확도 평가, 태블릿 카메라/온도/배터리/지연시간 측정은 미수행.
- 이 테스트의 합성 이미지는 코드 검증용이며 실제 학습 데이터가 아닙니다.

## 남은 입력과 완료 조건
1. 2023 일반형 엔진룸 실차 이미지와 10개 클래스 초안의 전문가 검수.
2. 차량 단위로 분리된 학습/검증/시험 라벨 데이터. 현 시점에 사용 가능한 검수 완료 데이터는 확보되지 않음.
3. GPU 학습과 동일 test 비교. 기본 목표는 mAP50-95 +0.03 및 클래스별 recall 하락 없음.
4. 내보낸 ONNX의 실제 영상 정확도와 원본 체크포인트 대비 일치 검증.
5. 사용할 태블릿에서 표시 FPS, 처리 지연, 장시간 실행 및 가림/어두운 엔진룸 검수.

큰 모델을 선택했다는 이유만으로 기존보다 높은 성능이라고 주장할 수 없습니다.
