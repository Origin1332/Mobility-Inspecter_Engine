기준: 2026-10-29. 원본 코드 기준 커밋: aa93d6ba2dc7fb9aa53fa9b7e3fc20afcfc57e58.

## 입력 확인
- 최신 engine_room_seed_dataset.zip: 이미지 6장, 박스 30개, 12개 클래스 중 5개에만 라벨.
- 사용자 제공 2023 렉스턴스포츠 부품 카다로그: PDF 786쪽.
- 이미지 규격·bbox·파일 체크섬을 확인하고 실제 검수 팩 생성.
- 카탈로그에서 관련 235개 행을 추출. 배터리/퓨즈 박스 원문 표를 렌더링해 품번·옵션·적용 기간·인쇄 페이지 위치를 대조.
- 부품별 기본 연결과 검수 라벨을 사용하며 미식별 부품의 bbox를 추가하지 않음.

## 변경
- 10종 초안을 실제 데이터셋의 12종 순서로 교체. 모델 결과는 이름으로 ID 변환.
- 학습 모델 없이 기존 사진의 검수 박스를 볼 수 있는 오프라인 검수 모드.
- 박스 및 작은 부품용 목록에서 카탈로그 후보 검색.
- 관련 어셈블리/부속품, 품번 복사, 적용 조건 표시.
- 앱 내부 PDF 원문, 품번 행 강조, 분해도 이동, 확대와 페이지 이동.
- ZIP 경로·크기·중복·좌표·체크섬 검증, 유효한 새 팩 확인 후 교체.

## 검증 및 한계
- Python 단위 테스트와 실제 입력의 통합 검증을 수행.
- Android 단위 테스트/lint/APK는 GitHub Actions로 검증.
- 현재 데이터로 학습을 수행하지 않음. 7종 미라벨을 음성 샘플로 오인하지 않도록 검수 팩과 학습 변환을 분리.
- 카탈로그는 품번 후보/원문 조회이며 차대번호에 대한 장착 확정 기능이 아님.
- 실제 태블릿의 카메라, 화면 크기별 터치와 PDF 사용성, 장시간 구동 테스트는 미수행.
- 모델 성능 향상 수치나 새로운 실차 탐지 정확도는 주장하지 않음.
